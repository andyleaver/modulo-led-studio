The UI is organized to match how projects are actually created.

Creation pipeline
- Surface / Hardware starts new work
- Targeting defines where layers render
- Layers hold behaviors and compose the frame
- Behaviors generate pixels
- Rules automate state changes
- Operators post-process the composed output
- Export builds firmware or target output
- Diagnostics verifies the finished project
